what’s inside.

How do I set it up? ＋

Mac: unzip, then move Jyotish.app to Applications. Windows: extract the entire folder and run Jyotish.exe. These preview releases are unsigned; read the setup guide for platform limitations. No separate Python install is needed.

Does it work offline? ＋

Charts, rule-based readings, profiles and Python PDF generation work locally. Optional Qwen AI requires compatible WebGPU hardware and an initial model download. Imported books stay on your device; no ChatGPT API is required.

What makes a reading personal? ＋

The engine computes house ownership, placement, dispositors, planetary relationships, relevant divisional-chart comparisons, period activation and sampled transit contacts. It explains reinforcing and conflicting evidence, then presents conditional possibilities rather than a generic sun-sign paragraph.

How accurate is the interpretation? ＋

Traditional astrology is an interpretive framework, not a validated forecast of events. The app uses approximate Lahiri and ascendant calculations and selected documented rules. Full Shadbala, birth-time rectification and comprehensive yoga cancellation are not implemented. The method register explains the exact coverage.
